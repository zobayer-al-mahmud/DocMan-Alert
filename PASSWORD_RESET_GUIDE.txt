====================================================
 SUPER ADMIN PASSWORD RESET GUIDE
 DocMan Alert - Ananta Companies
====================================================

WHEN TO USE THIS
----------------
- You forgot the Super Admin (username: admin) password
- You need to rotate the password for security reasons
- The old password may have been exposed (e.g. shared in a file,
  email, chat, or backup that left the company)

WHAT CHANGED FROM THE OLD SCRIPT
---------------------------------
The old reset_admin_password.py had the password typed directly
into the file. The new version does NOT store any password in the
file - you type it in when you run the script, and it is never
shown on screen or saved anywhere except the database.

STEPS
-----
1. Open a terminal on the host PC (the Windows PC running the app).

2. Go to the project folder:
     cd /d "D:\ICT PROJECTS\Compliance Tracker"

3. Activate the virtual environment:
     venv\Scripts\activate

4. Run the script:
     python reset_admin_password.py

5. When prompted "New password:", type a new password and press Enter.
   - Nothing will appear on screen as you type - this is normal,
     it's hiding the password the same way a sudo/admin prompt does.
   - The password must be at least 10 characters, with at least
     one uppercase letter, one lowercase letter, and one digit.

6. When prompted "Confirm new password:", type the same password again.

7. When prompted to type YES to confirm, type exactly:
     YES
   (anything else cancels the reset - nothing is changed)

8. You should see:
     "Super Admin password has been reset successfully."

9. Go to http://192.168.14.33:5001/login and confirm you can log in
   as "admin" with the new password.

AFTER RESETTING
---------------
- Store the new password ONLY in your organization's password
  manager (or a similarly secure vault).
- Do NOT write it into any script, README, text file, or note that
  sits in the project folder or gets included in backups/zips.
- If the app is ever running while you reset the password, no
  restart is needed - the change takes effect on the next login.

IF THE SCRIPT FAILS
--------------------
- "Admin user not found" -> the "admin" username may have been
  renamed or deleted; check the Users list in the app first
  (logged in as another Super Admin, if one exists).
- Make sure you're running it from inside the activated venv, so
  Flask/SQLAlchemy imports work correctly.
